# Sprint 1 — Resurrection, phone, training, patterns

2026-11-02

## Direction

Synapse becomes a self-learning second brain that recognises patterns in what
you say and do, and shows you how you're evolving — fast, and in your pocket as
an installed app. Structure is built as we go and refined each sprint.

## Shipped

### 1. Back to life
- New Qdrant Cloud cluster; the old free cluster was deleted for inactivity.
- `scripts/reindex.mjs` rebuilds the vector index from Postgres (the source of
  truth), indexing each note and its facets exactly as capture does.
  Idempotent: facet point ids are derived from the note id.
- `netlify/functions/keepalive.mts`: a daily scheduled ping to Qdrant and
  Supabase so neither free tier reclaims the project again.

### 2. On your phone (PWA)
- Web app manifest, generated icons (one source, `src/lib/brandMark.tsx`),
  iOS home-screen icon, install button when the browser offers it.
- Service worker (`public/sw.js`): static assets cache-first; pages and
  read-only API calls network-first with the last good copy offline; data
  cache wiped on sign-out. Auth pages are never cached.
- Phone layout: opens on Home (dashboard) instead of the graph; bottom bar
  Home · Ask · Capture · Pulse · Train with a raised capture button.
- Speed: the last known brain is painted from local cache instantly and
  reconciled with the server; the graph stops rendering while hidden behind
  the dashboard (it was drawing 60 fps underneath).

### 3. Training (Size Blueprint)
Built to `docs/specs/size-blueprint-log.md` as `src/features/training/`:
program as data, rules as unit-tested pure functions, per-field saves, import
from the old artifact, voice logging, history, rest timer, and an agent tool
so "Ask" can answer questions about your training.

### 4. Pattern intelligence (v1)
- `src/lib/patterns.ts`: deterministic signals — rising and fading themes,
  loops you keep circling (with how heavy they feel), mood shift, stale
  actions, capture rate. Instant, computed on the client.
- `src/lib/highlights.ts`: Gemini reads across your notes, the signals and
  your training check-ins and writes 3–6 highlights (theme, shift, loop,
  link, growth, nudge), each citing the notes behind it.
- **Self-learning:** every highlight can be rated useful / not useful. Ratings
  are stored and fed into the next run as your taste, so it drifts toward
  what you value. (Classification already learns from your corrections.)
- Regenerates in the background when there's something new (new notes or a
  day passed), never more than once per 10 minutes.

## Calls made without asking (check these)
- Table names `training_sessions` / `exercise_sets` instead of the spec's
  `sessions` / `sets` (clearer next to the rest of the schema); `user_id` on
  every training row for simple, fast row level security.
- Weight trend: the spec's gap 1 (0.25–0.5 % of bodyweight) would *lower* the
  bar at 50 kg to 0.125 kg/week and contradict its own acceptance test. Kept
  0.25 kg/week as the floor (`max(0.25, 0.25 % × weight)`), show the band as
  info, flag > `max(0.5, 0.5 % × weight)` as fast, and added the 2-week stall
  check from gap 2.
- Phones open on Home, not the graph.

## Setup steps

   variables to the new cluster, then redeploy.
